# Types of CSS Position

- Static: The element stays in the normal page order.

- Relative: The element moves slightly from its normal spot

- Absolute: removes an element from the normal document flow and allows you to place it exactly where you want using directional offset properties.It leaves no gap behind, It anchors to its nearest "positioned" ancestor

- fixed : element stays in the same place on the screen, even when you scroll.

- sticky: The element sticks to the top when you scroll past it.
